# 전략과 검증 범위

## 목적

MB Quant의 전략은 특정 금융 분포를 활용해 일별 수익률의 상대적 상태를 관찰하는 연구용 예시입니다. 수익률 자체를 보장하거나 매매를 권유하는 모델이 아닙니다.

## 입력 데이터와 기간

- 데이터: `yfinance`의 일봉 `Open`, `Close`
- 기본 조회 기간: 실행일 기준 약 2년
- 조정 가격: `auto_adjust=True`
- 결측 처리: 전일 대비 종가 수익률을 계산한 뒤 첫 행을 제외

공개 데이터의 지연, 수정, 누락은 결과에 영향을 줄 수 있습니다.

## 신호 산출

일별 종가 수익률을 `r_t`라고 할 때 다음 순서로 계산합니다.

1. 15일 이동 표준편차를 MB 분포의 scale로 사용합니다.
2. `|r_t|`의 Maxwell–Boltzmann 확률밀도(`mb_pdf`)를 구합니다.
3. 최근 15일 `mb_pdf`의 하위 20%는 `+1`(매수/롱), 상위 90% 초과는 `-1`(매도/숏) 신호로 표시합니다.
4. 신호가 없으면 마지막 포지션을 유지합니다.

파라미터는 [`backend/services/strategy.py`](../backend/services/strategy.py)에 한 곳으로 통합되어 있습니다.

| 항목 | 값 | 의미 |
| --- | ---: | --- |
| `ROLLING_WINDOW` | 15 | 변동성·임계값 계산 창 |
| `LOWER_Q` | 0.20 | 매수 신호 기준 분위수 |
| `UPPER_Q` | 0.90 | 매도/숏 신호 기준 분위수 |
| `STOP_LOSS` | -1.5% | 거래 구간당 하한 |
| `TAKE_PROFIT` | +5.0% | 거래 구간당 상한 |

## 시점 정합성

신호는 해당 일의 **종가**를 포함해 계산하므로, 같은 날 시가부터의 수익률에 적용하면 미래정보를 미리 사용하는 오류가 됩니다.

MB Quant는 이를 피하기 위해 `t`일 종가에서 나온 포지션을 `t+1` 거래 구간부터 적용합니다.

```text
t일 종가로 신호 계산 → t+1일 시가에 포지션 적용 → t+1일 시가~t+2일 시가 수익률 계산
```

포지션 방향을 수익률에 곱한 후 손절·익절 한도를 적용합니다. 따라서 `-1` 포지션은 기초자산 하락에서 양의 수익률, 상승에서 음의 수익률을 갖습니다.

## 제공 지표

- 평균 월 수익률과 단순 연환산 수익률
- 월 단위 표준편차를 활용한 Sharpe ratio
- 전략 누적 수익률과 시장 누적 수익률
- 시그널·가격·누적 수익률 차트

## 해석 시 한계

이 결과를 전략 성과로 일반화하면 안 됩니다.

- 수수료, 세금, 스프레드, 슬리피지를 제외했습니다.
- 공매도 가능 여부·대차 비용·체결 가능 수량을 모델링하지 않았습니다.
- 파라미터 탐색, 표본 외 검증, 워크포워드 검증을 수행하지 않았습니다.
- 단순 월 수익률 합산과 단순 연환산은 복리 성과와 다를 수 있습니다.
- 시장 체제 변화나 데이터 공급자 오류에 취약할 수 있습니다.

따라서 이 프로젝트에서는 **분포 기반 신호를 서비스로 전달하는 구현 역량**을 중심으로 다루며, 투자 수익률 자체를 성과로 홍보하지 않습니다.
